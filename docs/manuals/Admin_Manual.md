# Administrator Manual

Welcome to the Admin Portal. This interface controls Content Management, User Administration, and Business Intelligence.

## 1. Content Management (DAM)
- **Uploading**: Navigate to `Publications > Upload`. Select a PDF file. 
- **Processing**: The system will automatically chunk the PDF, extract the cover image, and run NLP pipelines to generate keywords and a short summary.
- **Metadata Review**: Navigate to `NLP > Taxonomy` to review and adjust the AI-generated keywords before publishing.

## 2. Business Intelligence & Analytics
- **Executive Dashboard**: Provides a high-level view of Active Users, Revenue, and active PDF streams.
- **Finance Dashboard**: Tracks Stripe integrations, successful payments, and recurring revenue MRR.
- **Reporting**: Navigate to `Reports > Export` to generate CSV/PDF reports for external stakeholders.

## 3. User Management
- View active sessions, reset passwords, or revoke access.
- Assign roles (Reader, Editor, Admin).
- Review Security Audit logs for suspicious login activity.
